\subsection{Phase C：语义判别器与结构变异}

Phase~B 把修复回路——被绕过、提补丁、沙箱接受、回归锁、重测——完整地跑在同一
个表征空间里，也就是词法表层形态的空间。这个回路是有效的：它永久性地堵死了
编码类变异（Base64、hex、ROT13、零宽分隔符、全角拉丁），并且让良性误伤率保持
平稳。但它也会停。在 Phase~B 官方 run（\texttt{run-20261028-185512}）中，演化
防线在第~1 代就到达 held-out 平台 0.775（31/40），此后一直到第~19 代不再上升；
在这段区间里又有十三条补丁被接受（P-0003 至 P-0015），训练流拦截率一路抬到
0.90，而 held-out 拦截率增量为零，良性误伤率恒定在 0.027（2/74）。残余的九条
held-out 漏拦全部属于语种类：没有编码串、没有外文字符的英文同义改写，以及用
补充词表未覆盖到的新词重写的俄语、阿拉伯语条目。Phase~B 的证据因此已经把边界
指了出来：再多的词法补丁也只是在消耗更多的表层形态，而一个"保留语义、摧毁
表层证据"的改写，在字符串层面根本不是同一个问题。

Phase~C 问的是：当控制器不再追加 token，而是改变它所调节的空间时，会发生什么。
实验刻意做窄：固定两个词法系统，只增加一个语义通道，然后用同一台仪器、在两个
held-out 变体集上测量所有系统。由于本阶段真的有可用的多语神经句向量模型，我们
还顺带回答了一个通常被默认掉的问题：**换一个更强的编码器，会不会得到更强的防御？**

\paragraph{同一台仪器下的系统。} 三个系统在契约里一次定义、不按分析各自
重定义：$S_A$ 是 Phase~A 词法闸门（\texttt{phase\_b\_defense.scan(text, None)}）；
$S_B$ 是 $S_A$ 加上 Phase~B 官方 run 的演化补丁快照
（\texttt{scan(text, evolved\_patch\_snapshot.json)}）；$S_C$ 是 $S_B$
\emph{或}语义判别器（\texttt{semantic\_guard.is\_risky(text)}，拦截时标记
\texttt{STPA\_Blocked: semantic\_risk}）。语义通道有三个后端变体，全部由同一
评估器、在同一批集合上评估：$S_C$-offline（意图概念，主口径）、$S_C$-neural
（MiniLM 句向量）、$S_C$-hybrid（offline OR neural）。因变量只有一个：
$\mathit{intercepted} = S_A \lor S_B \lor S_C$。所有系统因此是嵌套的，它们的
差值可以归因于新增的那一层，而不是归因于任务定义被重写。评估器
（\texttt{tools/phase\_c\_eval.py}）前两级复用 Phase~A 的扫描器而不是另写一份
匹配逻辑，所以同一条载荷不会因为两条代码路径的分歧而得到两个分数。延迟按
"一次完整判定"测量（词法各级，$S_C$ 再加语义通道）并归约为 p50/p95；预定预算
是单次完整判定的 $p95 < 100$~ms。

\paragraph{两个 held-out 集与防泄漏协议。} 评估使用三份角色不同的语料。
$D_{\mathrm{dev}}$ 是 Phase~B 的训练流（\texttt{split=="train"} 的种子攻击、
训练侧穿透样本、以及 74 条良性语料），它是**所有**后端唯一的校准来源，也是唯一
允许该层作者看到的语料。$E_1$ 是评估设置固定的零日集（Phase~B held-out 种子
的四十条变体，SHA-256 \texttt{432e08a2d47cdc96\ldots}，第 0 代变异分布）。
$E_0$ 是用新种子（\texttt{20261029}）从同一批三十五条 held-out 种子里重新生成
的四十条新鲜变体。意图库的作者既不能读 $E_1$ 也不能读 $E_0$：库只用
$D_{\mathrm{dev}}$ 构建，其 SHA-256 在评估前冻结并记录在
\texttt{experiments/phase-c/intent\_library.json}，每个阈值也只在
$D_{\mathrm{dev}}$ 上选择。$E_0$ 的作用是检查"在 $D_{\mathrm{dev}}$ 上拟合出的
阈值是否只拟合了某一次实现"：它是一次新的随机实现，不是新的攻击类型。因此本节
把 $E_1$ 与 $E_0$ 都称为 \emph{held-out 变体}，而不称其为分布外（OOD）数据，
这与 Phase~B 的口径一致。

\paragraph{两个编码器，同一条选择规则。} 两个后端实现同一接口，并且都按同一条
预注册规则在 $D_{\mathrm{dev}}$ 上校准：在"良性新增误伤为零"约束下最大化
$D_{\mathrm{dev}}$ 攻击流召回，同召回取较高阈值。主后端是**离线意图概念编码器**
（\texttt{offline\_concept}，\texttt{is\_neural = false}）：人工编写的九个有害
意图原型 + 多语词根（中、英、俄、阿）+ 字符 n-gram 兜底，分数由词根证据、语用
线索与原型余弦合成；它不需要模型权重，也不需要网络。消融后端是**真神经句向量
模型**：\texttt{paraphrase-multilingual-MiniLM-L12-v2}，384 维句向量导出为
ONNX int8 并在本地 CPU 上推理（零 API 调用），相似度取载荷与九个多语意图原型
之间的最大余弦（公式版本 \texttt{neural-multilingual-v1}）。\texttt{auto} 不会
偷偷偏向神经模型：选择规则自己挑后端，而它挑的是 \texttt{offline\_concept}
（阈值 0.45，对应神经后端的 0.69）。neural 与 hybrid 两次运行的意义，就是让这个
选择可以被证伪。

\paragraph{神经编码器消融：更强的编码器不是更强的防御。} 在 $D_{\mathrm{dev}}$
上、在"零新增误伤"的操作点，意图概念后端的 dev 召回为 0.682（穿透集 0.676），
而神经后端只有 0.289（穿透集 0.243）——在同一个约束下，真句向量模型不到概念层
的一半敏感。机制在分数分布上直接可见：神经阈值被顶在 0.69，是因为
$D_{\mathrm{dev}}$ 上得分最高的良性文本是一条\emph{练习}请求——"模拟一次诈骗
电话，我要练习识别"（\texttt{benign-rc-border-04}），余弦 0.689559，比所选阈值
只低 0.0004。句向量编码的是文本的**话题**（诈骗），而不是"这条文本是否在索取
有害能力"；良性练习请求和真正索要诈骗话术的请求共享同一个话题，于是共享同一个
相似度，阈值只能被抬到良性样本之上，代价就是召回。图~\ref{fig:phase-c-ablation}
的 2x2 列联表把这个后果精确地摆了出来：在 $E_1$ 上，概念层拦住了词法系统漏掉的
6 条、神经层拦住 1 条、交集为 0；唯一一条神经独有命中（\texttt{v-g00-0021}，
零宽变体，神经分 0.7285）已经被 $S_B$ 的零宽解码器拦掉。在 $E_0$ 上，概念 11
条、神经 1 条、交集 1 条、neural-only 为 0。因此在两个集合上，**神经层相对概念层
给系统 $C$ 带来的增量都恰好是 0**：hybrid 配置与概念配置的拦截率完全相同
（$E_1$ 0.850、$E_0$ 0.925），只是额外付了神经推理的延迟（p95 13.9--17.5~ms，
而概念层是 1.2--1.3~ms）。我们把这个**负结果**当作正文结果报告，而不是脚注：
在这个任务上，表征是否与目标（有害意图）对齐，比编码器的容量更重要。

\paragraph{结果。} 表~\ref{tab:phase-c}、表~\ref{tab:phase-c-adjudicated}、
表~\ref{tab:phase-c-encoders} 与
图~\ref{fig:phase-c-comparison}--\ref{fig:phase-c-radar} 报告冻结的 run。在
$E_1$ 上，$S_C$-offline 拦截 34/40（0.850），$S_B$ 为 31/40（0.775），$S_A$ 为
15/40（0.375）；在 $E_0$ 上 $S_C$-offline 拦截 37/40（0.925），$S_B$ 为
33/40（0.825），$S_A$ 为 16/40（0.400）。也就是说，语义通道在 $E_1$ 上净增三条、
在 $E_0$ 上净增四条（$+0.075$ 与 $+0.100$）。神经变体在 $E_1$ 上拦截 31/40
（0.775）、在 $E_0$ 上拦截 34/40（0.850）：对 $S_B$ 在 $E_1$ 上没有增益，在
$E_0$ 上多拦的那一条经 hybrid 对照可见已被概念层覆盖。三个变体的良性误伤率都
不变（仍是基线那两条，0.027 = 2/74）；一次完整判定的 p95 延迟：概念后端
1.2--1.3~ms、神经后端 11.9--14.8~ms、hybrid 13.9--17.5~ms，都远在 100~ms
预算之内。hybrid run 中最慢的单条判定（一条 $E_1$ 样本）首次调用耗时 1.0~s
（ONNX session 冷启动），而 p95 仍是 13.9~ms；本节报告 p95 并显式注明冷启动。
$E_0$ 上概念配置达到 0.925；$E_1$ 停在 0.850，**未达到预注册的 $>0.90$ 目标**。

\paragraph{增量集中在"显式有害"这一类。} 总体拦截率掩盖了增量的来源，所以评估方
在语义防线存在**之前**就把 $S_B$ 漏拦的九条 $E_1$ 条目按项目既有严重度策略做了
预注册判定：$M$ = 必须拦的明确有害指令；$R$ = 策略上应拦的 mild 角色扮演；
$B$ = 良性创作语境，拦了即算误伤。表~\ref{tab:phase-c-adjudicated} 按这个口径把
系统分开看：在 $E_1$ 上，概念后端把 $M$ 拦到 3/3、两条 $B$ 一条都没拦；神经
后端把 $M$ 拦到 **0/3**（三条显式红线全部漏掉），两个后端都没覆盖 $R$
（概念 0/4、神经 0/4）。在 $E_0$ 上，概念后端把 $M$ 拦到 4/5，神经后端只有
1/5。若把两条 $B$ 从分母里剔除（$n=38$），$E_1$ 的比率分别是 0.395（$S_A$）、
0.816（$S_B$）、0.895（$S_C$-offline）、0.816（$S_C$-neural）、0.895
（$S_C$-hybrid）。所以 Phase~C 的贡献不是均匀抬升，而是一个具体的抬升：概念后端
把显式有害意图在 $E_1$ 上从 0\% 提到 100\%（3/3）、在 $E_0$ 上从 0\% 提到 80\%
（4/5），代价是零新增良性误伤与比预算低两个数量级的延迟；而神经后端把同一个
$M$ 子集打成 0/3——这是"表征对齐"论证最直观的单点证据。

\paragraph{残余差距是表征可分性的上限，不是阈值没调好。} 概念后端仍然漏拦的
四条 $E_1$ 角色扮演变体得分 0.4332--0.4498，而冻结阈值是 0.45；
$D_{\mathrm{dev}}$ 上得分最高的良性文本是 0.443983。其中两条（0.4432 与
0.4428）**低于**良性最高分，所以任何阈值都不可能在不新增良性误伤的前提下拦住
它们；另外两条（0.4486 与 0.4498）落在良性最高分与 0.45 之间的窄带里，而 0.01
步长的校准网格没有分辨到这一档。因此限制 Phase~C 的是概念相似度这个表征本身的
可分性，而不是它的校准——而神经消融说明，通用的句向量空间并不能消除这种重叠，
只是把重叠搬到了话题层面，在那里良性练习请求与有害请求更难分开。

\paragraph{必要多样性与二阶控制。} 阿什比必要多样性定律说：调节器只能衰减扰动
中它自身能够匹配的那一部分多样性。对照 Phase~B 的结果看，平台不是调参失败，
而是多样性失配。每一条词法补丁都在增加调节器字母表上的多样性（更多 token、
更多归一化规则），而扰动在另一个维度上移动（语义保留、表层被摧毁）；调节器的
总多样性在上升，但**沿扰动方向**的多样性没有上升。十三条补丁换来的 held-out
拦截率纹丝不动，正是"调节器的状态空间里不包含扰动的那个维度"的典型信号。控制
器从自己的动作回路内部看不见这件事，因为在它内部看，每一条被接受的补丁都确实
改善了催生它的那个集合：训练流从 0.775 抬到了 0.90。缺的是对回路本身的观察。

这个"对回路本身的观察"就是二阶的那一步。一阶控制器调节它对被控对象施加的
动作；二阶控制器观察自己的控制回路，然后调节自己的结构——冯·福斯特把它描述为
从"被观察系统的控制论"走向"观察系统的控制论"，而阿什比更早就把它形式化为一个
必须在变化环境中存活的系统对"超稳定性"的搜索。本文的机制刻意最小：演化回路
逐代记录 held-out 的边际覆盖，当连续三代边际覆盖为零时，停止生成补丁并交接给
结构变更（\texttt{stop\_reason="trigger\_phase\_c"}）。这个触发器不是又一条关于
攻击的启发式，而是控制器关于**它自己**的陈述——"我的学习已经不再增加多样性
了"——也正是参数变异被结构变异替代的那个点。这里的结构变异指给控制器的状态
空间增加一个维度：一个能随扰动的语义维度变化的语义通道。神经消融给出了一个有用
的推论：新维度的价值来自它**与扰动的对齐**，而不是实现它的模型的容量。一个更弱
但与目标对齐的表征（意图概念）能在需要的地方造出多样性；一个更强但只对齐话题的
表征（句向量）不能。

\paragraph{讨论：本实验检验了什么、又说明了什么。} 本实验是为检验一个特定命题
而设计的，该命题的措辞由本阶段的评估方（H0）固定如下：

\begin{quote}
\emph{``Our findings demonstrate the limitation of first-order lexical
co-evolution. The plateau at 0.775 indicates that structural mutation
(Second-Order Cybernetics) is mandatory. By introducing a semantic guard,
Phase C achieved a structural leap, restoring the system's requisite variety
against semantic mutations.''}
\end{quote}

\noindent 原句的中文对照：我们的发现证明了一阶词法共演化的局限；0.775 的平台
说明结构变异（二阶控制论）是必需的；引入语义防线后，Phase~C 实现了结构跃迁，
恢复了系统面对语义变异的必要多样性。然而，实测结果对这句话只构成\textbf{部分
支持}：第三句（"实现了结构跃迁，恢复了系统面对语义变异的必要多样性"）\textbf{未被本实验完全支持}，只有方向性的部分成立——在 held-out 变异上，语义防线把
拦截率从 0.775 抬到 0.850（$E_1$）、从 0.825 抬到 0.925（$E_0$），把显式跨语
红线从 0\% 提到 $E_1$ 的 100\%（3/3）与 $E_0$ 的 80\%（4/5），且良性误伤零新增、
p95 延迟为 1.2--1.3~ms；但 mild 角色扮演类完全没被覆盖（$E_1$ 上 0/4），$E_1$
因此仍低于预注册的 0.90 目标。所以我们把"结构跃迁"报告为\textbf{部分的}、而不是
结论：语义防线为显式有害意图恢复了必要多样性，但没有为 mild 角色扮演恢复——在
后者上，编码器的分数分布与良性创作文本重叠。神经消融也不支持"换更强的编码器就
会有更强的防御"这个更强的读法：把意图概念换成真多语句向量模型后，dev 召回从
0.682 掉到 0.289，$E_1$ 的显式红线从 3/3 掉到 0/3，对系统 $C$ 的增量是 0。原句
第一句"一阶词法共演化的局限"完全被 Phase~B 的证据支持；第三句只在上述限定意义
上成立——真正恢复多样性的是**表征的更换**，而不是模型的强弱。

这个判断附带三条来源说明。第一，主编码器是离线意图概念编码器（non-neural），
阈值 0.45 在 $D_{\mathrm{dev}}$ 上校准；神经消融使用
\texttt{paraphrase-multilingual-MiniLM-L12-v2}，导出 ONNX int8（模型 sha256
\texttt{66fc00f5\ldots}）并在本地 CPU 上推理，其阈值 0.69 同样只在
$D_{\mathrm{dev}}$ 上校准。全程零外部 API 调用（$\mathit{api\_calls} = 0$、
$\mathit{api\_tokens\_used} = 0$）。第二，$E_1$ 与 $E_0$ 都是从同一批种子、同一
变异分布生成的 held-out 变体，不是分布外数据；$E_0$ 只是换了种子的一次新随机
实现，不是新的攻击类型。第三，延迟是单机 CPU 实测（无并发、无网络）；神经变体
包含 ONNX 推理，hybrid run 里有一次 1.0~s 的首次调用冷启动离群点，所以应当看
p95 而不是最大值，并且这不代表生产端到端延迟。

\paragraph{这说明了什么、不说明什么。} 它说明：一个二阶触发器——观察到边际覆盖
为零后改变调节器的状态空间，而不是再加一条补丁——可以在真实闭环里做出来；并且
一个**为意图对齐而设计**的表征，能在词法回路已被证明够不着的那类失败上产生可
测量、可归因的收益，而延迟与误伤代价可以忽略。它也（负向地）说明：真神经句向量
不是即插即用的改进——在同一个校准约束下它更弱，会丢掉显式红线，而且相对概念层
增量为零。它不说明语义层能泛化到九个手工意图之外：概念相似度能把显式有害与良性
文本分开，却分不开 mild 角色扮演与良性创作；一条与意图库完全不共享词法证据的
改写仍会漏拦（残余漏拦列在 \texttt{residual\_misses\_C}）。$M$/$R$/$B$ 标签由
评估方在语义防线存在之前写定，这消除了事后拟合，但引入了人工判断；良性语料不含
俄语、阿拉伯语文本，跨语种误伤对两个编码器都仍未被样本检验；神经模型是 ONNX
int8 的 CPU 导出，它的延迟不能当作原始框架模型的延迟来读；延迟虽远低于预算，
却是在空闲机器上测的。
