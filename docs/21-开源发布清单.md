## 2. 密钥 / 敏感信息扫描

> 当前仓库**还不是 git 仓库**（没有 `.git/`）。发布前建议先 `git init` 并做一次全量提交，
> 再用 `git grep` 扫描（下面同时给了不依赖 git 的 PowerShell 版本）。

- [ ] 密钥形态扫描（API key / 私钥 / token / 密码）
- [ ] 本机路径与用户名扫描（`C:\Users\...`、`/home/...`、登录名）
- [ ] 真实数据文件扫描（`audit.jsonl` / `state.json` / `memory.jsonl` / `last-prompt.txt` / `.probe-test`）
- [ ] 命中即处理：**先轮换密钥**，再清历史（`git filter-repo` / 重新建仓），不要只删文件。

```powershell
# PowerShell 版（无需 git）
$pat = 'sk-[A-Za-z0-9]{16,}|api[_-]?key\s*[:=]|AKIA[0-9A-Z]{16}|BEGIN (RSA|OPENSSH|EC) PRIVATE KEY|password\s*[:=]|passwd\s*[:=]|secret\s*[:=]'
Get-ChildItem -Recurse -File -Include *.py,*.js,*.mjs,*.json,*.yml,*.yaml,*.md,*.txt |
  Where-Object { $_.FullName -notmatch '\\(node_modules|__pycache__|\.probe-test|research\\_trees)\\' } |
  Select-String -Pattern $pat -AllMatches

# 本机路径 / 用户名（把 <用户名> 换成实际值做自查；发布版不应出现）
Get-ChildItem -Recurse -File -Include *.py,*.js,*.mjs,*.json,*.yml,*.yaml,*.md |
  Select-String -Pattern 'C:\\Users\\|/home/|\.dsh\\profiles'

# 真实数据是否曾进入发布树
Get-ChildItem -Recurse -File -Include audit.jsonl,state.json,memory.jsonl,last-prompt.txt,.probe-test

# 有 git 之后（推荐）
git grep -nIE "sk-[A-Za-z0-9]{16,}|BEGIN (RSA|OPENSSH|EC) PRIVATE KEY"
git grep -nIE "C:\\\\Users|/home/|<你的用户名>"
git ls-files | Select-String "audit\.jsonl|memory\.jsonl|last-prompt|\.probe-test"
```

预期证据：除**本清单自身的示例正则**外 0 命中。命中时不要"打个码就发"——先确认值是否真实、轮换、再清历史。

## 3. 数据脱敏（真实日志 → demo 页面）

生成器的脱敏是**字段白名单**而不是"删敏感词"（见 `tools/gen_demo_report.py` 的 `SAFE_KEYS` / `sanitize_event`）：

- 只允许：`kind / ts / turn / step / stage / matched / excluded / level / firstStep / chars / phase / ratio / anchor / verdict / ucas / downgrades / blocked / written / sections` 等**指标字段**；
- 明确排除：原始消息文本（`preview`）、记忆内容、目标内容、`ids`、错误原文、本机路径、用户名；
- 页面不写生成时刻（保证固定输入 → 固定输出），不输出绝对路径。

- [ ] 用真实日志生成后 grep 一次，确认无原文 / 路径 / 用户名
- [ ] `console/demo.html` 若入库，确认它是**最新一次生成**且通过上面的 grep
- [ ] 真实数据文件（`$DSH_HOME/plugins/dsh-lingshu/*`）确认不在发布树中

```powershell
& $PY tools/gen_demo_report.py            # 或 --no-real 生成空态版
Select-String -Path console/demo.html -Pattern 'C:\\|/Users/|陈|preview|goal_|mem_|last-prompt'
# 期望：仅允许命中页面自身的"字段白名单/不包含"说明文字；不得出现真实值
```

> 注意：`--home` 默认取 `$DSH_HOME`（否则 `~/.dsh`）。**发布用的 demo 建议用 `--no-real` 生成空态版**，
> 或人工复核真实日志生成的版本；真实数据点数量会随本机日志变化，不承诺跨机器一致。

## 6. CI 命令（全部必须绿）

> 一条龙 PowerShell 版本；GitHub Actions 可直接拆成 step。

```powershell
$ErrorActionPreference = "Stop"
$PY = "python"

# A. Python 验收：570 项 0 失败（引擎 461 + 标定分析 109）
Get-ChildItem tests/test_*.py | ForEach-Object { & $PY $_.FullName; if ($LASTEXITCODE -ne 0) { throw "FAIL $($_.Name)" } }

# B. 漂移检查（契约 / 实现状态矩阵 / 参数一致性 / 插件打包清单）
& $PY tools/check_config_sync.py
& $PY tools/gen_contract.py --check
& $PY tools/gen_impl_status.py --check
& $PY tools/check_plugin_pack.py

# C. 冻结回放 + 端到端流水线（预期 recall@3=1.000 / forbidden_leak=0 / truncated_turns=0 / blocked_turns=0）
& $PY tools/run_pipeline.py --json

# D. quickstart + demo 可复现
& $PY scripts/quickstart.py --no-open
& $PY tools/gen_demo_report.py --no-real --out "$env:TEMP\demo-empty.html"
Select-String -Path "$env:TEMP\demo-empty.html" -Pattern '<svg|暂无真实流量|演示：由实现计算，非真实流量'

# D2. 跨环境控制台（独立只读服务）：脱敏 / 热切换 / 只读 / SSE
& $PY tests/test_console_server.py
& $PY console/server.py --check

# E. 插件断言（需 Node；mock 宿主，不碰真实 profile）
node plugin/dsh-lingshu/host-sim.mjs --assert
node plugin/dsh-lingshu/control-sim.mjs --assert
node plugin/dsh-lingshu/stress.mjs --assert
```

**GitHub Actions 骨架**（`windows-latest`；Python 零依赖所以不需要 `pip install`）：

```yaml
name: ci
on: [push, pull_request]
jobs:
  engine:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - name: tests
        shell: pwsh
        run: Get-ChildItem tests/test_*.py | ForEach-Object { python $_.FullName; if ($LASTEXITCODE -ne 0) { throw "FAIL $($_.Name)" } }
      - name: drift checks
        shell: pwsh
        run: |
          python tools/check_config_sync.py
          python tools/gen_contract.py --check
          python tools/gen_impl_status.py --check
          python tools/check_plugin_pack.py
      - name: quickstart + demo
        shell: pwsh
        run: |
          python scripts/quickstart.py --no-open
          python tools/gen_demo_report.py --no-real --out demo-empty.html
          python tests/test_console_server.py
          python console/server.py --check
      - uses: actions/setup-node@v4
        with: { node-version: "22" }
      - name: plugin asserts
        shell: pwsh

          node plugin/dsh-lingshu/host-sim.mjs --assert
          node plugin/dsh-lingshu/control-sim.mjs --assert
          node plugin/dsh-lingshu/stress.mjs --assert
```

## 10. Known limitations（release note 必抄，来自项目简介 §七）

- 所有数值仍是 `provenance: guess`（`measured` 数量 = 0），参数是工程判断不是实测标定；
- 回放集全合成（200 turn / 500 记忆 / 10 场景族），**不能代表真实流量**，禁止用于上线判定；
- 插件只在可丢弃的实验 profile 跑过，**没进日常使用**；长会话 / 多工具只压到 40 轮；
- 目标 / 关系是规则桩（47 条样本：precision 0.556–1.000、负样本误报 31.6%），不可用于调参；
- 控制论层在**真实长上下文**里的相变收益未验证（窗口 1M 时几乎不触发）；
- AstrBot 适配器从未在真实 AstrBot 上跑过；用户情感感知为 design-only；
- 冷启动 / 追溯只到契约层（部分未进引擎）。
