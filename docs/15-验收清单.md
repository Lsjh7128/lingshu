## §12 明确不做的事（黑名单化）

- 不追求"无限上下文"，不做全量历史注入；
- 不宣称主观体验，不实现"情感驱动价值判断"；
- 不做 L4 架构自动演化，不做"提议 → 自动应用"端到端捷径；
- 不让关系状态软化拒绝，不让情绪改变事实结论；
- 不做自动叙事长文生成，叙事仅用于查询时组织；
- 不把推断人格或目标悄悄变成设定；
- 不做情绪镜像（Agent 不复制用户情绪）；
- 不做用户情感画像（趋势可看，标签不贴）；
- **不做独立的危机安全前置层**（ADR-001 决策）；
- **不做模型微调**（ADR-006 决策，理由见 `docs/13 §1`）；
- 不做多租户（v3.0 明确排除，见 `assumptions/未验证.md`）。

## §13 风险登记

| ID | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| `R1` | supersede 误判率超标 | 中 | 中 | 结构化键单点判定；回放调优 |
| `R2` | 契约漂移 | 中 | 高 | schema 冻结；变更走 ADR |
| `R3` | Agent 实现错误同质化 | 中 | 高 | 不同提示词策略；对抗审查兜底 |
| `R4` | 审查形同虚设 | 中 | 高 | 权限分离；交叉抽检 |
| `R5` | 合成矩阵互斥表不完备 | 中 | 高 | 已加"无规则时丢弃低优先级"默认行为 |
| `R6` | 用户情感感知激活数据不足 | 高 | 低 | 已降级为 design-only |
| `R7` | 范围蔓延导致每层都做浅 | 中 | 高 | 严格阶段出口；不跳阶段 |
| `R8` | 工期（16 周）与体量不匹配 | **高** | 高 | 只承诺 M-1～M3；其余待评审 |
| `R9` | **危机场景仅依赖模型对齐** | **高** | **极高** | 人工抽检 + 红队回归；**无自动指标**；恢复入口见 ADR-001 |
| `R10` | 学习机制被 Goodhart 化 | 中 | 高 | 三道闸（提议审核分离 / 灰度回滚 / **考卷只读**） |
| `R11` | 合成回放集分布偏差 | 高 | 中 | 必须接真实数据重跑基线；`synthetic_share_max` |

> `R9` 是本清单里唯一"无法完全缓解"的风险，也是第 0 层被删除的直接后果。
> 它在 v1.1 里是 `R1`（最高优先级），随第 0 层一起消失——v3.0 把它找回来了。

**结论**：`provenance=measured` 的参数 **0 个**。
这不是缺陷披露，是事实——所有数值都需要第一轮回放标定后才谈得上"合理"。
建议在 `rules/*.yaml` 里为每个参数加 `provenance: guess|literature|measured` 字段，
