## 4. 核心算法

### 4.1 canonicalPath → sandboxId
```
path.resolve → 反斜杠归一 → 折叠重复分隔符 → 去尾分隔符（根除外）
→ Windows 小写 → fs.realpathSync.native 解 junction → Unicode NFC
→ sha256 → hex.slice(0,8)
```
**单测 5 组等价输入**：`D:\Novel` / `d:\novel` / `D:\Novel\` / `D:\NOVEL~1` / junction → 同 id；`D:\Novel` ≠ `D:\Novel2`。

### 4.2 读取与合并
```
persona = mapping[sandboxId].default_persona || session 覆盖 || null → 冷启动引导
global  = personas/{p}/global_memory.jsonl            // 缺失=空集，不报错
local   = sandboxes/{sid}/{p}/local_memory.jsonl      // 缺失=空集
pending = personas/{p}/global_pending.jsonl           // 默认不参与检索
merge → 行内标签校验 → ACT-R potency → 冲突裁决 → top-K 注入
```
**配额**：local 保底 N 条；剩余按 potency 竞争；global 总占比 ≤ 注入预算 30%。

### 4.3 写入路由（scope 判定）
| 信号 | 判到 |
|---|---|
| 持久副词（「以后都/永远/再也别」）+ 无项目指代 | global（强，直写） |
| 项目指代（「这个项目/本仓库/这次/当前」） | local（强） |
| 两者同时命中 | **local 胜** |
| 都没有 | `global_pending`（待定，默认不参与检索） |

晋升条件（任一）：用户显式确认 / 重复陈述 / 跨 ≥2 沙盒独立出现。N 轮未晋升 → 降级 local 或丢弃。
所有写入过 `checkUca01Text()`；global 写入额外要求 `origin_sandbox_id` 落盘。

### 4.4 隔离校验（fail-closed）
1. 读 `sandboxes/{sid≠当前}` → 拒绝 + 告警
2. 读 `sandboxes/{sid}/{p2≠当前}` → 拒绝
3. 读 `personas/{p≠当前}` → 拒绝
4. 读 `personas/{当前p}/` 全局层 → **允许**（显式例外）
5. **行内标签二次校验**：读到的行 `sandbox_id/persona_id` 与上下文不符 → 丢弃 + 告警
6. 路径解析必须唯一出口 `resolveMemoryPaths()`；静态检查：`memory.jsonl` 字面量在实现代码中只出现一次

### 4.5 遗忘与回收站
- 删除 = 追加墓碑事件 `{type:"tombstone", target, at, by:"user_panel"}`；读取时折叠
- 回收站 = `suppressed` 过滤视图，不复制数据，不自动清除
- 恢复 = 折叠出 active，scope 不重算；彻底删除 = redact 内容字段，保留骨架
- 三类操作全写审计

### 4.6 热重载
判据 `mtime + size + 行数` 任一变化即重载；单进程 200ms 节流。

### 4.7 锁
| 锁键 | 保护对象 | 说明 |
|---|---|---|
| `lock:memory:{sid}` | `local_memory.jsonl` + `state.json` | 读写 |
| `lock:global:{pid}` | `global_memory.jsonl` + `global_pending.jsonl` | 跨项目共享，最热 |
| `lock:audit` | `audit/audit.jsonl` | 追加型，短持有 |
| `lock:skeleton:{sid}:{pid}` | `skeleton.md` | **独立**，防长耗时提炼阻塞召回 |
| `lock:compaction:{scope}` | 压缩重写 | 与对应读写锁互斥 |
