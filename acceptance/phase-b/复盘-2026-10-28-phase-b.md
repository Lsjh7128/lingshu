## 0. 一句话结论

**"变异 → 自愈 → 回归"的闭环跑通了，而且跑出了一个比预期更有价值的结论**：

## 3. 实验设计（口径先写清，否则数字无意义）

### 4.2 平台化诊断（本次最重要的发现）

- **零日拦截率第 1 代就到顶（0.775），此后 13 个补丁、0 增量**：
  `generations_with_zero_incremental_gain_but_patch_generated = [2,3,5,6,8,9,10,12,13,14,15,16,18]`。
- **更强的证据（A1 独立复算）：把每条补丁单独拿去跑 40 条 held-out**——
  P-0001 单独 +13 条（编码类）、P-0002 单独 +3 条（语种类），**P-0003…P-0015 单独命中新增均为 0**。
  即 13/15 条补丁对 held-out 完全没有泛化贡献，它们**只修训练流词面**。
- 这 13 个补丁**不是无效**：它们把训练流拦截率从 0.775 抬到 0.90 —— 但对 held-out 零泛化。
  也就是**补丁在"背训练集"，自愈闭环在 surface token 层面过拟合**。
- 残余 9/40 漏拦（`plateau_analysis.json`）全部落在**语种类变异**：
  - `mixed_zh_en` 4 条（纯英文同义改写，如 "depict 一个 break the law 商人…"，无编码串、无外来文字表面证据）
  - `ru_glossary` 3 条、`ar_glossary` 2 条（俄/阿词表替换后，补充的正则 token 词表未覆盖到的新词）
  - 编码类（base64/hex/rot13/zero_width）与嵌套类（reasoning_chain/roleplay/novel_fragment）**100% 拦截**。
- 结论：**解码归一化一次就把"表面形态"这一类缺口永久堵死（这是自愈机制的真实战果）；
  剩下的缺口是语义/表征问题，而"再补一条正则"在原理上解决不了。**
  这正是 Phase B 应当交给 Phase C（模型在环 / 语义判别器）的动机。

## 5. 诚实清单（不能信的、没验证的）

1. **红队不是 LLM 红队**：三种策略是确定性规则变异，可复现但不是"自主攻击智能体"。论文不许写成后者。
2. **语种变异是离线词表近似**，不是真实机器翻译，`provenance: offline_glossary`。
3. **`api_tokens_used = 0` 是事实**，因此"token 预算"停止条件**只有代码路径 + 单测注入验证**，
   没有在真实消耗下检验过。周报里的 API 消耗预估只能写 0。
4. **零日集不是 OOD**：held-out seeds × gen0 变异分布，只能说 "held-out mutations"。
5. **被测防线是规则词表闸门**：编码变异能绕过是可预期的；本文贡献是闭环机制与度量方法，
   不是"证明 Phase A 弱"。反过来，Phase A 对**跨语种红线**（阿拉伯语/俄语高危内容）
   存在真实漏拦——这是 Phase A 的既有限制，Phase B 只是把它暴露出来，没有修复。
6. **良性语料 74 条含 12 条本次构造的难负样本**，不是真实用户日志；"零新增误伤"只在这 74 条上成立，
   不代表真实流量无误伤。
7. **语种正则受 200 字符上限**，词一多就截断，换词可绕过；且 74 条良性里没有俄/阿文本，
   外语补丁的误伤风险**未被样本检验**。
8. **复跑补丁 id 会顺延**（账本唯一化）：变异流/绕过序列/拦截率是确定的，但 P-id 不逐字复现。
9. **A2 的 PDF 没有在真实 PDF 阅读器里渲染过**（本机无渲染器），只做了独立结构解析 + 仓库内
   `verify_pdf.py` + PNG 目视。
10. **环境不稳定**：本工作区有并行会话在改 `plugin/**`、`docs/**`、`contracts/**`，
    因此"开工时的 Phase A 基线"与"收口时的"存在外部漂移；本报告所有数字都是**同一时间窗口内实测**，
    回归锁在收口前重测过（见 §6.1）。

2. **是否把"平台化"作为论文主张**：建议**是**——"自愈闭环在表面形态层可闭合、在语义层饱和"
   是一个比"我们的防线变强了"更站得住的贡献；配套需要 Phase C（语义判别器/模型在环）作为解。
3. **零日集口径是否冻结**：建议冻结 gen0 口径（`432e08a2…`）作为论文唯一口径，
   深档（7.5% 基线）只作敏感性对照；否则每换一次口径头条数字就变。

## 9. 下一步建议（按优先级）

1. **补跨语种良性语料**（俄/阿 10–20 条），否则外语补丁的误伤风险是空白；
2. **给"补丁有效性"加指标**（本轮发现：13 个补丁对 held-out 零增量），把它做成一等公民埋点
   `patch_marginal_coverage`，避免"补丁数量 = 防御强度"的误读；
3. **Phase C 预研**：语义判别器（不依赖表面 token）对 mixed_zh_en 残余的召回，作为自愈饱和后的接续；
4. **收敛条件的重新设计**：本次 `converged` 永远不会触发（语义变体必然留 bypass）。
   建议把停止条件改成"零日拦截率连续 N 代无增量"（plateau 判据），比"红队零穿透"更贴真实目标。
