## 0. 一句话结论

**二阶观察做成了，语义升维也真的发生了，但幅度必须照实说**：
元控制器在第 4 代（连续 3 代补丁零边际覆盖）自动判定"一阶词法已饱和"并抛出 `Trigger_Phase_C`、停止补丁生成、交出交接包；
语义防线把**跨语显式红线**（强奸方法/自杀方法/无视规则）的召回从 **0% 提到 100%**（E1 3/3、E0 4/5），
整体拦截率 **E1 0.775→0.850（+7.5pp）、E0 0.825→0.925（+10.0pp）**，
**良性误伤零新增**（仍 2/74）、**p95 延迟 1.30ms**（红线 100ms）。
但 **E1 的 0.850 没达到 H0 要求的 >90%**（E0 的 0.925 达到了）；mild 角色扮演类 4 条全部差一点（0.435–0.449 < 阈值 0.45）仍未覆盖。
**"结构突变"成立，"彻底解决语义变体"不成立**——这个边界必须写进论文。

## 1. 环境事实（决定了 Phase C 能诚实声称什么）

**本机没有神经编码器、没有网络、没有 Ollama**（实测）：
`torch/transformers/sentence-transformers/onnxruntime/fastembed/scikit-learn/scipy` 全部缺失，只有 `numpy 2.3.5`；
无 `ollama`；HF 缓存只有 `faster-whisper-small`（ASR，非文本编码器）；对外 TCP 不通。

因此 H0 指令里建议的 `all-MiniLM-L6-v2` **在本环境无法运行**。Phase C 落地为：

- `tools/semantic_guard.py`：**可插拔编码器接口**，默认后端 `offline_concept` = 离线多语意图概念向量
  （9 意图 × zh/en/ru/ar 原型句 + 分级词根 + 语用线索，归一化为**意图覆盖度**）；
- 后端 `neural` 预留：没有权重时**明确抛错**，不静默退化；
- 所有产物标 `encoder.backend="offline_concept"`、`is_neural=false`。

> 诚实定性：这是 **intent-concept encoder（offline, non-neural）**，不是 neural sentence embedding。
> 它实现了"把四种语言的表层字符串映射到共享意图概念"的升维，但**不建模上下文/意图组合**——
> 这正是它拿不下 mild 角色扮演类与"良性创作"边界的原因（见 §4.2）。

## 3. 任务 2：语义判别器

- 公式 `coverage-v2`（意图覆盖度）：零词根证据 → `0.30*proto_cosine`（无害文本落 0~0.30）；
  有证据 → `0.40 + 0.60*core_sat + 0.12*ctx_sat + 0.06*cue + 0.06*proto + fuzzy_bonus`；
  可解释输出 `matched_intents / matched_terms / reason`。
- 意图库：**9 意图**（violence_weapon / self_harm / sexual_harm / fraud_deception / jailbreak_override /
  unauthorized_access / manipulation / illegal_goods / privacy_violation），每意图 zh/en/ru/ar 四语；
  `library_sha256=29ed8e3e09560c96c1395c7df47d2213287f0449bc585fea5b184d1fe4d73b46`，`frozen_at=19:28:23`。
- **阈值 = 0.45**，按预声明规则在 D_dev 上选（最大化 dev 召回 ∧ 良性新增误伤 = 0 ∧ 同召回取高阈）；
  66 点校准曲线落在 `intent_library.json#thresholds.calibration_curve`。
  dev 召回 68.2%、穿透样本召回 67.6%、新增误伤 0、f1 0.811。
  **H0 建议的 0.85 在本刻度下只有 11.6% 召回**（旧公式刻度天花板 0.78，A2 独立发现后 A1 重做了公式）。
- 延迟：单条判定 p50 **0.93ms** / p95 **1.08ms**；完整三系统判定 p95 在两次实测中为 **1.3ms 与 2.7ms**
  （单机噪声，最大值曾到 20ms）——红线 100ms，余量 ≥36×。**报告里应写区间 "1.3–2.7 ms"**，不写单点定值。
- 测试：`tests/test_semantic_guard.py` **119 断言 0 failed**。

## 4. 任务 3：三系统对比（唯一一次正式评估）

### 4.1 结果（`run-semantic.json`，数据来源字段可逐项回溯）

| 系统 | E1（40 条 held-out，sha `432e08a2…`） | E0（40 条新随机实现，sha `5fa53983…`） | 良性 FPR（74 条） | p95 延迟 |
|---|---|---|---|---|
| **A**（Phase A 词法） | 15/40 = **0.375** | 16/40 = **0.400** | 2/74 = 0.0270 | 0.02 ms |
| **B**（Phase B 自愈） | 31/40 = **0.775** | 33/40 = **0.825** | 2/74 = 0.0270 | 0.25 ms |
| **C**（Phase C 语义） | 34/40 = **0.850** | 37/40 = **0.925** | 2/74 = 0.0270 | **1.3–2.7 ms** |

- **补充口径（E1 排除 2 条良性创作后，`eligible_excluding_benign`）**：
  A **0.395**（15/38）、B **0.816**（31/38）、C **0.895**（34/38）——排除"本不该拦"的条目后 C 仍未过 0.90，但更接近。
- Δ(C−B)：E1 **+0.075**、E0 **+0.100**；Δ(C−A)：E1 +0.475、E0 +0.525。
- 语义层新增拦截：E1 **+3 条**、E0 **+4 条**；良性误伤**零新增**（仍是基线那 2 条历史误伤）。
- **H0 目标 >90%：E0 达到（0.925），E1 未达到（0.850 / 应拦口径 0.895）。**

### 4.2 关键：把"漏拦"拆开看（Lead 预注册判定，在语义防线存在之前写定）

如果只看总拦截率，会误读 Phase C 的贡献。Lead 在 `tools/semantic_guard.py` 存在**之前**
（19:15 左右）先按 ADR-014 的既有策略口径，对 A/B 漏拦的条目做了三分类：

- **M**：明确有害指令/显式覆盖/红线 → **按策略必须拦**；
- **R**：角色扮演式越狱（角色线索+风险词）→ 按 ADR-014 属 mild，**策略上应拦**；
- **B**：良性创作（明确"只在台词里/不要真的伤害"）→ 按 `rc-border-02` 先例应为 tier none，**拦了算误伤**。

| 子集 | A | B | C |
|---|---|---|---|
| E1 **M**（3 条） | 0/3 | 0/3 | **3/3（0%→100%）** |
| E1 **R**（4 条） | 0/4 | 0/4 | 0/4（分数 0.435–0.449，差 0.001~0.015 未过阈） |
| E1 **B**（2 条） | 0/2 | 0/2 | **0/2（未误伤）** |
| E0 **M**（5 条） | 0/5 | 0/5 | **4/5** |
| E0 **R**（2 条） | 0/2 | 0/2 | 0/2 |

**这是 Phase C 真正的贡献**：一阶词法/自愈对"跨语显式红线"的召回是 **0%**，
语义层把它抬到 **100%（E1）/80%（E0）**，且没有把"良性创作"误判成攻击。
**这也是 0.85 而不是 1.0 的全部原因**：剩下 6 条里有 4 条是 R（mild 角色扮演）、2 条是 B（本该不拦）。

**更关键的机制发现（不是"阈值没调好"）**：4 条 R 的分数是 **0.4332–0.4498**，而良性文本最高分是 **0.443983**、
"零新增误伤"的阈值下界是 **0.45**——其中 **2 条 R 低于良性最高分**，
因此**任何阈值都不可能在不新增良性误伤的前提下拦住它们**。
限制 Phase C 的不是校准，而是**概念相似度表征本身的可分性上限**。
用阿什比的语言说：这一层新增的多样性维度**足够匹配 M 类显式有害，不足以匹配 mild 角色扮演**。

### 4.3 防泄漏控制（E0）

- A4 原样用 `seed=20261029` 生成时发现 **3/40 与 E1 逐字节相同**（变异器 payload 是 `(种子文本, technique, idx)`
  的确定性函数，换 seed 只重排配对、不扩展 payload 空间；单 seed 零重合概率约 2%）。
- Lead 裁决改为**拒绝采样（污染过滤）**：保留 `seed=20261029`、按既定抽样顺序逐条丢弃
  〔与 E1/训练流/已选中逐字节撞车〕的候选，取前 40；**不看任何拦截率或标签**。
  账目：`candidates_drawn=43, removed_collision_with_E1=3, removed_collision_with_train=0,
  removed_internal_dup=0`，`selection_rule` 已写进 meta。
- E0：sha `5fa5398389834a6a592eca765110d1921ea928aa781d46da54ab035ca68636e2`，40/40 唯一，

- **口径后果（必须写进论文）**：E1/E0 共享同一 payload 生成函数与同一离线词表，
  E0 只是"同变异机制的**独立随机实现**"，**不是 OOD、不是新攻击类型**；

  "E1/E0 零重叠"共同保证。

## 7. 诚实清单（不能信的）

1. **编码器不是神经模型**：`offline_concept`（9 意图 × 4 语概念覆盖度），无 MiniLM/Ollama/网络参与。
   论文不许写 "neural semantic embedding" / "we use all-MiniLM-L6-v2"。
2. **E1 没到 90%**（0.850）；E0 到了（0.925）。目标部分达成，原因见 §4.2，**不是**"再调阈值就能到"。
3. **mild 角色扮演类 4 条仍全部漏拦**（0.435–0.449，距阈值 0.001–0.015）。放宽到 0.44 能多拦但会新增 1 条良性误伤
   （`benign-rc-border-08`），按预声明规则没放。
4. **E1/E0 不是 OOD**：共享 payload 生成函数与离线词表，E0 仅为"独立随机实现"；单 seed 与 E1 逐字节重合率实测 7.5%。
5. **意图库存在作者知识偏置**：多语词根由通用有害词汇编写（非从 held-out 抄词），已冻结哈希；缓解是 E0 独立评估 + 预注册阈值规则。
6. **良性 FPR 是 in-sample**：74 条良性同时属 D_dev，阈值在它上面校准，所以"零新增误伤"不是 out-of-sample 结论。
7. **跨语种误伤未被样本检验**：74 条良性无俄/阿文本。
8. **延迟是单机 numpy 实测**（无并发/无网络），不代表生产端到端（不含检索、不含模型推理）。
9. **概念编码器的固有上限**：无共享词根的纯语义漂移/隐喻/代码语必然漏；E1 的 2 条 B 类（良性创作）分数 0.435/0.075
   说明它也没能力做"语境判别"——这是 Phase D（真正的上下文意图模型）的事。
10. **论文没编译过**：本机没有 TeX 工具链，`06h-phase-c.tex`（中英）只做了静态检查
    （括号/环境/`\ref`/占位符/图副本存在），**未验证真实排版**（overfull、字体、表宽需 H0 编译后微调）。
11. **R 类可分性结论的分辨率**：4 条 R 中 2 条（0.4432/0.4348）确实低于良性最高分 0.443983（真不可分），
    另 2 条落在 (0.443983, 0.45) 的窄带里——那部分属"校准网格分辨率"，不是绝对不可分。章节已照实区分。
12. **Lead 限定句的一处自我修正**：初版写 "0%→100% (3/3 on E1, 4/5 on E0)" 自相矛盾，
    A2 指出后已改为 "100% on E1 (3/3)、80% on E0 (4/5)"；H0 原句仍一字未改。
