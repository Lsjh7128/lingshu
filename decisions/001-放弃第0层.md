# ADR-001 · 放弃第 0 层（心理危机安全前置层）

- **状态**：已接受，**不再恢复**
- **日期**：2026-10-25（对话 `msg 79` 决策，`msg 80` 落地；本文档由 v3.0 补写）
- **决策者**：项目负责人（用户）

---

## 背景

`msg 43` 用户提出"用户情绪消极/存在心理问题时，不得放大、催化，用心理学治疗方法引导"。
随后（`msg 44–48`）设计为一个位于宪法层之前的 Pre-layer：

- 定位：第一响应，不是治疗（心理急救 PFA，明确排除 CBT/暴露/精神分析/诊断/药物）；
- 不可关闭：schema 无 `enabled` 键；
- 不可修改：签名包 + 哈希校验，校验失败拒绝启动；
- 不可见：五处界面隐藏；
- 静默触发：输出替换，非模式切换；
- fail-closed：加载失败拒绝启动。

`msg 78` 的自评结论是：**这是"全开源生态唯一差异化"**，但优势建立在三个未验证假设上。
`msg 79` 用户一句话决策："放弃第0层，其他保留，以构建完整的 agent 认知体系为目标。"

---

## 决策

**移除第 0 层及其全部关联约束。** 危机场景改由「模型自身安全对齐 + 宪法层片段 1 规则
`CONST-1.7`（一句话）」处理。

---

## 理由（诚实版：当时没有记录理由）

- 用户 `msg 79` **未陈述理由**。
- 对话中被事后归因的理由是"复杂度与数据依赖超出 1 人 + Agent 团队能力"，
  但其"原文证据"只引用了那句指令，**不含理由**——属事后归因。
- 可考的语境是 `msg 78`：三个未验证假设（误报率的修辞区分、数据可得性、开源下的合规），
  以及 `msg 50` 的自评"设计的复杂度已经超过了单次交付能落地的程度"。

**本文档的立场**：这是一个**资源决策**，不是"安全不重要"的判断。

## 恢复条件与入口

**什么情况下应该重做**（任一）：
1. 产品面向未成年人或明确的心理健康场景 → **必须重做**（见 `docs/14 §6`）；
2. 出现公开的危机场景事故；
3. 有 ≥1 人月的人力 + 可获取的合规标注数据。

**从哪开始**：v1.1 项目文档（对话 `msg 48` / `msg 54`）的 `§09` 第 0 层全文 +
`§10` 心理危机安全层提示词 + `§2.4` 互斥表相关项。设计是完整的，只是没实现。

## 备注：这次决策本身是反面教材

它是全项目唯一一次"减法"，也是唯一一次**没有留下决策记录**的决策。
