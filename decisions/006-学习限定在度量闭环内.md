# ADR-006 · 学习限定在度量闭环内（不做微调）

- **状态**：已接受
- **日期**：2026-10-25（v3.0 新增）
- **决策者**：设计方

---

## 背景

"让 Agent 有学习能力"有三种常见理解：

1. **记住经验**（状态积累）——已有，记忆插件就是；
2. **调整自己**（参数/策略适应）——原设计有 L1–L4，但从未落地；
3. **长出能力**（微调/训练）——完全没有。

v3.0 需要明确：要不要做 3？如果做 2，做到什么程度？

---

## 决策

**只做 2，且限定在度量闭环内；明确不做 3。**

具体：

| 层 | 内容 | 本期 |
|---|---|---|
| L0 度量 | 四组指标 + 回放器 | ✅ 必须先建 |
| L1 参数 | `τ`/`topK`/`minWeight`/扩散折扣，离线搜索 + 人工确认上线 | ✅ |
| L2 权重 | 检索排序权重，只提议 | ⏸ |
| L3 提示词 | 含**编码器提取阈值**，只生成 diff | ⏸ 只做队列 |
| L4 架构 | Schema、分层、取代规则 | ❌ 永不 |

**学习的定义**：`学习 = 产生提议`，不等于应用提议。提议生成方与审核方必须分离。

---

## 理由

### 为什么不做微调

1. **样本不足**：编码器微调需 ≥1000 条标注，现在 0 条；
2. **违反可回滚**（不变量 I4）：权重一改，回滚只能回整包，"部分回滚"做不到；
3. **归因断裂**：微调后"变好了"无法归因到具体改动，与整个项目的"可解释"目标冲突。

### 为什么必须先从度量开始

- 没有指标 → 不知道什么叫变好 → L1 无从自动（`msg 12` 自己列的第一阶段就是这个）；
- 没有归因 → 不知道是参数问题还是提示词问题（`msg 14` 明确警告）；
- 没有回放 → 灰度无法判定"这次改动是否更好"，只能靠感觉。

### 为什么加"考卷只读"这道闸

`msg 12` 的黑名单保护了"审核门禁"，但**没有保护评估口径**。
不保护它的后果是：系统最先学会的是改考卷（调低阈值、塞简单样本、挪护栏上限），
而这三件事都不需要改任何"规则"。

---

## 后果

- 学习机制不是"开箱即用"，而是 6–8 周的独立工程（`docs/13 §8`）；
- 它依赖可观测性（M-1），**不可独立先行**；
- 代价：短期内"Agent 不会自己变强"——这是刻意的，见 `T1 可靠性 > 拟人度`。

---

## 改变条件

只有在同时满足以下三条时，才会考虑微调：
1. 有 ≥1000 条标注数据；
2. 解决了"部分回滚"（如 LoRA 增量权重可独立加载/卸载）；
3. 回放器能证明微调后的改进不是"过拟合回放集"。
