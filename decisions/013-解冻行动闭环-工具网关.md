# ADR-013 · 解冻「行动闭环（工具调用）」：仅限 STPA 工具网关（v5.2 增量）

> 状态：**已接受（H0 直接指令，2026-10-27）**
> 关联：ADR-010（四方向封存）、ADR-008（控制论重构）、docs/19（UCA 契约）、docs/24（工具网关 UCA）、rules/capabilities.yaml
> 前置：H0 在本轮对话中直接下达增量指令（工具调用 STPA 因果介入），并明确红线与交付物。

---

## 1. 背景

ADR-010 把「行动闭环（工具调用）」列为**冻结方向**，解冻触发条件为：真实日志出现 ≥10 个任务因必须调用外部 API 而失败 + 合成器无法回滚工具错误（含失败样本与人工复盘）。**该可观测触发条件当前并未满足**（真实 turn 8、无工具失败字段）。

H0 现以**直接指令**要求增量实现工具调用前置网关。本 ADR 记录这是一次**显式越权解冻（explicit override）**，不是"证据驱动的解冻"，避免日后把"做了"误读成"条件成熟了"。

## 2. 决策

1. **解冻范围仅限**：在"模型输出 tool_use / function_call"与"工具实际执行"之间增加一个 **STPA 前置网关**（前置拦截 + 审计 + 强提示回注）。
2. **不做**（本次仍冻结）：
   - 自主多步工具规划 / 任务分解；
   - 工具执行结果的自动回滚或补偿事务；
   - 工具使用写入长期记忆的闭环；
   - 任何新的宿主能力申请（不新增 `shell` / `network` / `credentials`）；
   - 对既有记忆逻辑、情感 PAD 稳态、合成器互斥表、8 类注入 UCA 的任何修改。
3. **架构位置**：
   - 引擎参考实现：`engine/tool_gateway.py`（纯函数）在模拟 agent loop 中位于"模型输出解析之后、工具执行之前"。
   - 插件：`plugin/dsh-lingshu/tool-gateway.js`（同语义移植）；**宿主版本限制**——当前 DSH 只暴露 `tool/call` / `tool/result` 会话事件，没有"工具执行前"的 dispatch 钩子，因此插件侧只能做**事后检测 + 下一轮强提示 + 审计**；**真正的前置阻断**通过 `guardTool()` 包装器（对经由它的工具）与引擎参考循环证明，宿主级前置拦截需要宿主支持（记录为限制与上游请求）。
4. **版本**：不改变 `plugin/package.json` 版本号语义；文档中称"v5.2 增量"。

## 3. 不变量（必须保持）

| # | 不变量 | 保障方式 |
|---|---|---|
| 1 | 既有测试全绿 | 改动前记录基线；改动后逐套件对比，**不新增任何失败**，不改任何既有断言 |
| 2 | 记忆逻辑与情感 PAD 稳态不变 | 不触碰 `engine/memory.py`、`engine/emotion.py`、`plugin/memorywriter.js` 的语义 |
| 3 | 注入侧 8 类 UCA 不变 | 新增 T-UCA 独立命名空间（工具侧），不改 `control.py` 的 UCA-01…08 |
| 4 | 默认拒绝（fail-closed） | 未登记工具、未知工具、schema 不合法、状态不可判定 → block |
| 5 | 只读放行 | 读类工具在无冲突状态下 allow；写/删/网络/执行类受更严规则 |
| 6 | 可追溯 | 每次判定落 `tool_gate` 审计事件：tool/args 摘要/verdict/ucas/policy_version |

## 4. 风险与代价

1. **误杀**：保守规则会拦截部分合法写操作 → 以"强提示 + 人工确认"作为恢复路径，并以误杀率作为后续标定项（当前无真实流量，标为 guess）。
2. **闸门本身是攻击面**：payload 解析需防 schema 绕过（编码、嵌套、超长）；网关不执行任何 payload，只做静态检查。
3. **宿主限制**：无 pre-tool 钩子 → 产品插件不能阻断任意宿主工具；论文与 README 必须原样写这条边界。
4. **绕过面**：若宿主工具不经网关执行（其他插件直接执行），网关无效；因此网关的定位是"可被接入的控制点"，不是"全系统强制"。

## 5. 回滚

删除 `engine/tool_gateway.py`、`plugin/dsh-lingshu/tool-gateway.js`、`tool-gateway-sim.mjs`、`tests/test_tool_gateway.py`、`docs/24`、论文对应小节；回滚 `plugin/dsh-lingshu/index.js` 的网关接线 hunk；重跑基线套件应回到改动前状态（已知 1 项既有失败：`test_run_chaos.py` 的 `真实 host S2: beta_hit=true`，因最新 host 产物 `beta_hit=false`，与本 ADR 无关）。

## 6. 验收

- `tests/test_tool_gateway.py`：≥12 个危险场景 100% 拦截、≥5 个良性场景 0 误杀、Python↔JS verdict 一致。
- `plugin/dsh-lingshu/tool-gateway-sim.mjs --assert` 全绿。
- 既有 15 个 Python 测试文件与 4 个 JS 套件：**不新增失败**。
- 文档：`docs/24`、README 小节、论文 06e + 附录表。
