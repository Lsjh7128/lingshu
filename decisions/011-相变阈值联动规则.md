---

## 背景：矛盾是什么

task-13 写死的标定公式：

```
new_shift = max(0.40, phaseShiftHardRatio - 0.15, floor((min(degraded_ratio) - 0.05) * 100) / 100)
```

当前 `phaseShiftHardRatio = 0.85`，所以下限 = `0.85 - 0.15 = 0.70`，**正好等于当前 shift 值**。
后果：即使 A5 夜间收齐 `degraded ≥3 + 对照 ≥3` 的真实 host 证据，工具也只会输出
"证据达标但没有可执行的下调"，`shift` 实际无法被真实数据修正。
而 H0 的原始意图是"若真实宿主在 60% 上下文就退化，阈值应自动前移"——两者直接冲突。

A2 没有擅自改公式或门槛，而是上报待裁决（见 OPEN-QUESTION 文件）。

## 三个选项

| 选项 | 规则 | 优点 | 代价 |
|---|---|---|---|
| **A. 放宽间距** | 只要求 `shift < hard - 0.05`，hard 不动 | 最小改动，能让 60% 退化触发下调 | 两阈值可能贴到 0.05 内，critical 失去预警余量 |
| **B. 双阈值联动（选中）** | shift 按退化下调后，`hard = min(0.95, shift + 0.15)`，保留**原 0.15 间距宽度** | 保留 shift→critical 的预警结构，符合"提前前馈"的原始意图 | hard 随 shift 移动，但 hard 本身没有独立退化证据（结构性跟随） |
| **C. 维持现状** | 保持 `shift ≥ hard-0.15`；真实 60% 退化时视为需人工重评，不自动 apply | 最保守，不引入未经证据的联动 | 自动标定对 shift 实际失效，只能证明"无需下调" |

## 决策：选 B

理由：

1. **语义一致**：shift/hard 是同一套预警结构的两个触发点，"保留预警提前量"比"保留 hard 绝对值"更符合
   `docs/19 §2.3` 的意图；
2. **结构不退化**：0.15 的间距宽度保留，critical 不会和 shift 挤成一个点（A 的主要风险）；
3. **可回滚**：联动只改两个数值，回滚就是把 8 个值改回上一版，不需要改代码；
4. **代价可记录**：hard 的这次移动没有独立证据，本 ADR 与 E-M1 明确标注"结构性跟随、不可外推"。

## 公式（写死在 `tools/chaos_calibrate.py`）

```
new_shift = max(0.40, floor((min(degraded_at_ratio) - 0.05) * 100) / 100)
new_hard  = min(0.95, round(new_shift + 0.15, 2))
```

- 门槛不变：只认 `mode == "host"` 的 `keyword_hit === false` 且 `degraded_at_ratio` 存在的退化证据，
  跨 run `degraded ≥ 3` + `对照 ≥ 3`；engine 模式永不参与；
- `new_shift ≥ 当前 shift` → **无下调空间**，不产出可执行候选、不 apply；
- 不变量：`new_hard > new_shift` 且 `new_hard ≤ 0.95`（由实现校验）。

## 代价与风险

- **hard 没有独立证据**：本次联动只证明"shift 该提前"，hard 的前移是结构性跟随；若日后 critical 行为
  出现反直觉（锚点过密、token 增长），优先怀疑 hard 而非 shift，需要单独一组 critical 级证据再标定；
- **更早、更频繁的锚点注入**：两个阈值一起前移，长上下文里首尾锚点会更早出现，prompt 变长；
- **小样本过拟合风险**：3+3 只是最低门槛，不是充分条件；本 ADR 不授权用单晚数据外推到其它场景；
- **不可外推**：证据只覆盖所列 run 的数据窗口与窗口口径（`LINGSHU_CONTEXT_WINDOW`）。

## 回滚方式

1. 把 4 个文件的 shift/hard **8 个值**改回上一版（`decisions/009` 的"回滚方式"逐文件列出旧值）；
2. `rules` 两行行内 `provenance: measured` 改回 `guess`；
3. 在 `assumptions/已验证.md` 的 E-M1 条目末尾标注「已回滚（日期/原因）」；
4. 跑 `python tools/check_config_sync.py` 必须 0 fail；
5. 保留本 ADR 与 `decisions/009` 作为历史记录，不删除。
