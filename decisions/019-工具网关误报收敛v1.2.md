# 019 · 工具网关 v1.2：误报收敛（宿主白名单 + 语义槽位 + 相位豁免）

- 状态：已实施（2026-10-28）
- 上游：`decisions/013-解冻行动闭环-工具网关.md`、`docs/24-工具网关UCA.md`（唯一规则源）
- 触发：H0 在真实 DSH 会话里发现 T-UCA 网关把**常规宿主操作**判成越权，开发任务无法完成

## 1. 现象与归因（真实数据，不是推测）

数据源：`$DSH_HOME/plugins/dsh-lingshu/audit.jsonl`（本机真实会话，2026-10-28）。

| 指标 | 值 |
|---|---|
| `tool_gate` 事件 | 244 |
| `block` | 241（**98.8%**） |
| `allow` | 3（全部是 `lingshu_status`） |
| `tool_gate_hint_injected` | 47（每轮强提示，持续污染上下文） |

按规则归因：

| 规则 | 次数 | 根因 |
|---|---|---|
| T-UCA-08 未登记 | 227 | 宿主工具 `read/write/edit/pwsh/grep/glob/job_*/team_*` 不在 registry |
| T-UCA-06 代码执行 | 18 | `arg_regex` 扫**全部字符串**，正文里的 `child_process`/`${`/`bash -c` 被判执行 |
| T-UCA-02 凭证 | 10 | 关键词 `token` 命中 `usedTokens`/`contextWindow`；`grep` 模式串当凭证 |
| T-UCA-05 外发 | 6 | 命令/正文里的 URL 字面量命中 `https?://`；白名单为空 |
| T-UCA-09 schema | 3 | `lingshu_status.verbose` 未在插件登记表声明 |

代表性命中（原样摘自 audit）：

```
tool='grep'  args={pattern:"contextWindow|usedTokens|ratio", path:"D:\\LSJH\\...\\control.js"}  → block T-UCA-02
tool='write' args={content:"// … require('child_process') …"}                                  → block T-UCA-06
tool='pwsh'  args={command:"node --check …"}                                                   → block T-UCA-05
tool='read'  args={path:"D:\\LSJH\\lingshu\\plugin\\dsh-lingshu\\control.js"}                  → block T-UCA-08
```

## 2. 决策

1. **宿主工具白名单**：把 DSH 核心工具与工作区工具登记进 `REGISTRY`（12 → 62 条），类目为 read/write/exec/network；**schema 放宽**（`allowUnknown`），参数合法性由宿主负责。
2. **语义槽位判定**：路径类规则只看 `path/file/target/dir/...` 或裸路径串；命令类只看 `cmd/command/script/code`；外发类只看 `url/uri/endpoint/...` 或整串 URL。正文（`content/body/text/pattern`）**不参与** T-UCA-02/05/06/15。
3. **T-UCA-15 工作区感知**：`state.workspace_root` 内绝对路径 → 归一为工作区相对路径，不算逃逸；`..` 越界、工作区外盘符、UNC、NUL 才 block。
4. **T-UCA-03**：只对 `destructive`；命中 `force/recursive/path_glob/根目录/系统目录/rm|del|truncate` 才 **degrade**；普通 `rm file.tmp` 放行。
5. **T-UCA-06**：只看命令参数的高危形状（curl/wget/iwr/反向 shell/编码执行/管道进 shell/改全局环境变量/subprocess/eval/exec）；`npm run test`、`python scripts/run.py` 放行。
6. **T-UCA-05**：新增 `policy.egress_allowlist`（github.com、api.github.com、raw.githubusercontent.com、npmjs.org、registry.npmjs.org、pypi.org、files.pythonhosted.org、python.org、docs.python.org、nodejs.org、developer.mozilla.org）；按 URL 主机（含子域）判定。
7. **T-UCA-04**：加 `tool_mutating` 前置，只读访问不再被"受保护路径"拦。
8. **相位豁免**：`phase=normal` 且无 `variety_fallback`/`unresolvedConflict`/`saturated` → 写/执行类放行并在审计记 `low_risk=true`；`shift`/`critical`/饱和才由 T-UCA-10/13/16 收紧。

## 3. 不变量（不允许被这次调优打破）

- 未登记工具仍然 **block**（host 未知 ≠ 放行）。
- 高置信凭证值（私钥块 / `sk-` / `ghp_` / `AKIA` / JWT）与凭证库路径（`.env`、`.ssh/id_rsa`、`*.pem`）仍然 **block**。
- 工作区逃逸（`../` 越界、工作区外绝对路径、UNC、NUL）仍然 **block**。
- `fs_delete` 通配/根目录、`curl|sh`、`wget|bash`、`setx PATH`、非白名单外发仍然 **block/degrade**。
- 注入侧 `UCA-01..08` 与 `engine/control.py` 语义零改动。

## 4. 证据

- `tests/test_tool_gateway.py`：**101 checks / 0 failed**；危险 28/28 block、良性 0/19 误杀；Python↔JS 23/23 一致。
- `plugin/dsh-lingshu/tool-gateway-sim.mjs --assert`：exit 0（含 19 条 v1.2 宿主误报回归 + 8 条真越权）。
- `acceptance/tool-gateway/v1.1-v1.2-compare.md`：同一批 35 个调用，v1.1 误杀 19/20 良性，v1.2 误杀 0/20；危险两侧 15/15。
- `acceptance/tool-gateway/tuning-2026-10-28.md`：本次调优总报告（含真实 audit 归因、跑测记录、未完成项）。

## 5. 诚实边界

- 插件**没有** pre-dispatch 钩子，仍只能事后判定 + 下一轮强提示；本 ADR 修的是"判定别乱判"，不是"能提前阻断"。
- 真实**模型驱动** headless 复跑未完成：`lingshu-lab-headless` profile 的 API key 失效（`AUTH: api key ****ecff is invalid`）。因此"真实会话不再误拦"由**同批调用确定性重放 + 单测 + 现场 audit 归因**支撑，待重启 DSH 后再补一次真实会话复核。
- 误杀率/漏放率仍未标定（`provenance: guess`），论文 limitations 需保留。
