## 1. 背景与性质

`docs/roadmap-persona-entity.md`（P0）把本方向定为**未实现 / 未排期**，并规定推进纪律：先补证据 → 写 ADR → H0 批准 → 再排期；其中 **P3（按工作区放开 exec）必须另立 ADR 并改能力声明**。

H0 现以**直接指令**要求落地。本 ADR 记录的是一次**显式越权解冻（explicit override）**，**不是**"证据成熟后的解冻"。日后不得把"做了"读成"条件到了"。

本轮实测的环境事实（决定做法）：

1. DSH 宿主仍**没有** workspace 概念，也没有"工作区切换"事件（`docs/00 §4.1` 的 H1–H6 无该项；探针与历史核实同结论）。→ **不做运行中热切换**。
2. 插件有两种安装形态（本机实测）：
   - `~/.dsh/profiles/desktop` → `link:C:/Users/陈岩/.dsh/plugin-src/dsh-lingshu-v1.0.0`（**发布副本**，当前会话的网关就跑这份）；
   - `lingshu-demo-profile` / `lingshu-lab-web` → `link:D:/LSJH/lingshu/plugin/dsh-lingshu`（**仓库**）。
   → 代码落在仓库；**发布时必须同步到 `plugin-src` 副本**，否则 desktop 不生效。这条要进发布清单。
3. P1 要改的 `plugin/dsh-lingshu/index.js` 在本轮被**另一会话并发编辑**（mtime 21:51:47，仍在变）。→ 本轮只落**不冲突的新模块**，接线另约（见 §5）。

## 2. 决策（本轮范围）

1. **P1 数据层**：新增 `workspace_{id}/` 目录层。**缺省零回归**——未显式配置时不启用该层，路径与旧 `index.js#stateDir` 逐字节一致；非法 id 拒绝并落审计，**不**静默回退到别的 workspace。
2. **P2 策略层**：工作区策略 = **deny-only 追加**。不允许 `allow`、不允许改判定顺序、不允许改提示文案；未登记规则 id fail-closed；空 `deny` 是"无操作"而不是"放开"。
3. **实现位置**：新增纯函数模块 `plugin/dsh-lingshu/workspace.js` + 自检 `plugin/dsh-lingshu/workspace-sim.mjs`。**本轮不接线 `index.js`**。
4. **明确不做**：P3（允许 exec / 改 `rules/capabilities.yaml`）；运行中热切换；自动数据迁移（旧路径不动）；多 Agent；人格复制/共享；手改 `docs/16`（生成器管）。

## 3. OQ 决议

| OQ | 决议 | 依据 |
|---|---|---|
| OQ-1 工作区 `{id}` 由谁赋值 | `LINGSHU_WORKSPACE`（env）> `workspaceId`（插件 config）> 空 = legacy 布局。**不猜**宿主 workspace（宿主无此字段） | 实测宿主能力 |
| OQ-2 与 `profileTag` 的关系 | 两维度**并存不合并**：workspace 在外层、profile 在内层（`workspace_<id>/profiles/<tag>`）；未设 workspace 时 profile 层保持旧路径 | 零回归优先 |

| OQ-5 宿主"工作区切换"事件 | 实测没有 → 热切换不做；"切换" = 新会话/新配置加载时选择目录 | 同上 |
| OQ-8 两会话并发切换的交叉写 | 本轮不解决，沿用现有单写者约束，标 ⏳ | PE-A7 未覆盖 |

## 4. 不变量与已验收（仅逻辑层）

| 不变量 | 保障方式 | 证据 |

## 6. 回滚

- 不设 `workspaceId` / `LINGSHU_WORKSPACE` → 立刻回到旧行为（legacy 布局）。
- 删除 `<数据根>/workspace_*` 目录即回滚隔离数据；旧文件从未被移动，故无需反向迁移。
- 代码回滚 = 删除 `workspace.js` / `workspace-sim.mjs`（当前无其他文件引用它们，删除不影响插件加载）。

## 7. 代价与风险

1. **RK-1**：目录隔离 ≠ 权限隔离（同进程、同 OS 用户）——对外文案不得称"安全隔离"。
2. **误配**：非法 id 回退 legacy 会"看起来配了但其实没隔离"，接线时必须落审计，否则是静默失效。
3. **并发编辑**：`index.js` 有两路写者时接线冲突风险高 → 本 ADR 选择"先落不冲突模块，接线另约"。
4. **发布漂移**：仓库与 `plugin-src` 副本是两份（见 §1.2）→ 发布清单应加"同步 plugin-src"一项。
5. **P3 未解冻**：任何"工作区 A 允许 exec"的说法现在都是错的。
